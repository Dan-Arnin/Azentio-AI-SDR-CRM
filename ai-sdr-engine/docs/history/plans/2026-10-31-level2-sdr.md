# Level 2 — Autonomous Engagement & Outbound Prospecting (AI SDR)

Status: In progress
Source: Hackathon_Challenge_Pack_Level1_Level2_8058.pdf, section 13 Level 2.

## Background
Level 1 (inbound capture → enrich → ICP → AI draft → approval → Resend send → reply → BANT → routing) is done and passes a
54-scenario end-to-end suite. This plan closes the Level 2 gaps found in the gap analysis.

## Frozen contracts (app/contracts.py — already added, do not change)
- `Assessment.intentStrength: "buying" | "exploring" | "none"` — genuine buying intent vs general curiosity.
- `Assessment.objections: list[{type, excerpt, handling}]` — type ∈ price | timing | incumbent | priority | fit | security | other; excerpt verbatim from the reply.
- `Assessment.competitors: list[{name, excerpt}]` — competitor / incumbent vendor mentions, verbatim excerpt.
- `Assessment.buyingSignals: list[{signal, excerpt}]` — e.g. "requested a call", "asked for demo", "shared evaluation timeline".
- `CohortDefinition.industries: list[str]` — matches company industry (case-insensitive substring), e.g. "Banking", "Islamic Banking", "NBFC".
- `HandoffCard.engagement: {emailsSent, repliesReceived, firstTouchAt, lastReplyAt, campaignName?, timeline:[{at, direction, subject, excerpt}]}`
- `HandoffCard.routingReason: str` — plain sentence explaining why this AE was chosen.

## Workstreams (parallel; each owns its files)
1. **Conversational intelligence** — `app/engine/extraction.py`, `app/engine/qualify.py`, `app/llm/decisions.py`, `app/pipeline.py` (build_card, ae_owner, route), `app/engagement/drafting.py` (objection-aware gap_fill only). AE territory/product routing rules.
2. **Outbound prospecting data** — `fixtures/apollo_mock.json`, `fixtures/knowledge.json`, `app/engine/enrichment.py` (search_cohort industries), `app/api/simulate.py` (`POST /v1/campaigns/{id}/simulate-replies`).
3. **Performance analytics** — `app/api/performance.py` (`GET /v1/performance?days=30`).
4. **Workspace UI** — `app/static/console.html` only.

## API contracts
`GET /v1/performance?days=30` →
```
{ "days": 30,
  "funnel": {"drafted","approved","sent","replied","positive","qualified","opportunities"},
  "inbound":  {"leads","drafted","approved","sent","replied","positive","qualified","opportunities","replyRate","positiveRate"},
  "outbound": { same keys },
  "campaigns": [{"id","name","theme","contacts","drafted","approved","sent","replied","positive","qualified","optOuts","stoppedOnReply","replyRate","positiveRate"}],
  "agentDecisions": {"aiCalls","aiTokens","draftsGenerated","guardrailBlocks","repliesClassified","routed":{"rep_review","human_review","nurture","suppressed","closed","existing_owner"}},
  "humanInterventions": {"approvals","edits","rejections","manualSends","ownerChanges","handoffsAccepted","handoffsReturned","tasksCompleted"},
  "decisionLog": [{"at","actor":"agent"|"human","who","leadId","leadName","text"}]   // newest first, max 60
}
```
`POST /v1/campaigns/{id}/simulate-replies` body `{"count": 3}` → `{"replies":[{"leadId","name","scenario","bodyText","runId"}]}`.
Picks enrolled contacts that were already emailed (fallback: any ACTIVE enrollment), assigns varied scenarios
(ready_to_buy, objection_incumbent_competitor, objection_price, curious_not_buying, referral, not_now, unsubscribe),
generates a realistic reply text (gpt-6-luna via app.llm.client.structured, with a fixture fallback), and ingests each via
`pipeline.ingest_reply` (origin "scripted") so the normal stop-sequence → qualify → route path runs.
